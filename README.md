# socket-emul

Эмулятор NFC-ридера с TUI-интерфейсом на Go. Поднимает WebSocket-сервер на `ws://localhost:8181` и позволяет вручную или в режиме спама отправлять клиентам сообщения о «приложенной карте» (хэш, UID, версия ПО ридера).

Клиент подключается так же, как в исходном примере:

```js
var exampleSocket = new WebSocket("ws://localhost:8181");

exampleSocket.onmessage = function (event) {
  let msg = JSON.parse(event.data);
  switch (msg.type) {
    case "hash":    /* приложили карту */  break;
    case "uid":                              break;
    case "version": /* версия ПО ридера */ break;
  }
};
```

## Сообщения

Все сообщения — JSON-текст, рассылаются всем подключённым клиентам одновременно:

```json
{"type":"version","data":"0.4"}
{"type":"uid","data":"00000000000280A0"}
{"type":"hash","data":"50903EF31F25667F2A70F0773E52B6FBC51160C7"}
```

## Требования

- Go 1.24+

## Запуск

```bash
go run .
# или
go build -o socket-emul.exe . && ./socket-emul.exe
```

Приложение откроет TUI и одновременно поднимет WebSocket-сервер на порту 8181.

## Управление

| Клавиша | Действие |
|---|---|
| `Tab` / `Shift+Tab` | переключить поле ввода (хэш / UID) |
| `F2` | отправить `{type:'version', data:'0.4'}` |
| `F3` | отправить `{type:'uid', data:'...'}` из поля UID |
| `F4` / `Enter` | отправить `{type:'hash', data:'...'}` из поля хэша |
| `F5` | вкл/выкл спам хэшем |
| `+` / `-` | интервал спама (от 50 мс до 5 с, по умолчанию 300 мс) |
| `Esc` / `Ctrl+C` | выход |

Хэш и UID вводятся один раз и сохраняются в полях — можно спамить одной и той же картой.

## Структура

- `internal/hub/hub.go` — WebSocket-сервер: учёт клиентов, рассылка сообщений, лог-события
- `ui.go` — TUI на bubbletea: поля ввода, спам-таймер, лог отправленных сообщений
- `main.go` — точка входа: запуск сервера и TUI
